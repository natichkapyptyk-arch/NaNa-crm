# Інструкція для Claude — СРМ салону краси (NaNa-crm)

## Як влаштовано
- Сайт — один файл `index.html` (клієнти — основне посилання, персонал — `#staff`).
- База — Supabase, проєкт `arkwtpihdaqnwhdcjpqf`. У `index.html` лише публічний anon key; секретний `service_role` ніколи не додавати в репозиторій.
- Будь-який коміт у `main` → Netlify сам оновлює сайт за ~1 хвилину.

## Хто вносить зміни
Зміни роблять **два чати**: Наталки (власниця репозиторію) і співавтора `PachoErerra`.
1. **Перед кожною зміною** — `git pull origin main`, щоб не затерти чужу роботу.
2. Якщо інший чат щойно (за останню годину) змінював ті самі місця — спершу сказати про це людині, з якою працюєш, і не перезаписувати чуже.
3. Коміт — з коротким описом українською, одразу в `main`.
4. Після зміни коротко сказати людині, що змінено, і що за 1–2 хвилини треба оновити сторінку.
5. Нічого не видаляти й не відкочувати без прямого прохання.

## Нотатки
Важливі рішення й зміни бази записувати в `docs/notes.md` (одна примітка — один рядок з датою).
